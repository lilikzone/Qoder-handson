# Qoder Hands-on

Materi hands-on lab **Workshop Qoder AI 60 Menit** (Bahasa Indonesia): Rules, Context, Agent, MCP, Testing, dan Debugging dengan studi kasus Task Management API (Python FastAPI).

| Berkas / Folder | Isi |
|-----------------|-----|
| [`HANDS-ON-LAB.md`](HANDS-ON-LAB.md) | Tahapan lab per sesi beserta Prompt 1–7 |
| `Workshop_Qoder_AI_60_Menit_Bahasa_Indonesia.docx` | Panduan fasilitator |
| [`bahan-workshop/rules/`](bahan-workshop/rules) | Teks Rule A, B, C siap salin |
| [`task-management-starter/`](task-management-starter) | Workspace awal peserta |
| [`task-management/`](task-management) | Solusi referensi / backup |

## Mulai cepat

```bash
git clone https://github.com/lilikzone/Qoder-handson.git
cd Qoder-handson/task-management-starter
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

Buka folder `task-management-starter/` di Qoder IDE, lalu ikuti `HANDS-ON-LAB.md`.
